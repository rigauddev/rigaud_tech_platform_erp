# On-Premise

Documento de entrada para deployment On-Premise.

Detalhes tecnicos estao em `docs/architecture/deployment/on-premise.md`.

## Principio

On-Premise e o mesmo ERP executando em ambiente local do cliente.

## Plataformas De Acesso

- Web;
- Android;
- iOS;
- Windows;
- macOS;
- Linux via navegador.

## Servidor Recomendado

Linux em producao.

Windows e macOS podem ser usados por usuarios finais e para desenvolvimento, mas nao sao a recomendacao primaria para servidor ERP de producao.
