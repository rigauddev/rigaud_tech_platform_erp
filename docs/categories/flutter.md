# Categories Flutter

REST-002 adiciona a feature Flutter `categories`.

## Estrutura

```text
erp-platform/frontend/lib/features/categories/
  data/
  domain/
  presentation/
  README.md
```

## Telas

- lista com árvore hierárquica;
- formulário de criação;
- formulário de edição;
- detalhe;
- ações de ativar, desativar e remover.

## Plataformas

A implementação usa widgets Flutter padrão e não adiciona plugins específicos de plataforma.

Compatibilidade esperada:

- Web
- Android
- iOS
- Windows
- Linux
- macOS

Builds nativos devem ser validados apenas em hosts compatíveis.
