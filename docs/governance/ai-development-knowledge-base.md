# AI Development Knowledge Base

A DOC-006 cria três documentos permanentes na raiz do projeto:

- `AI_DEVELOPMENT_CHARTER.md`;
- `ERP_DECISIONS.md`;
- `ERP_GLOSSARY.md`.

Eles devem ser lidos antes de qualquer task, junto com `AGENTS.md`, `erp-blueprint/MASTER_DEVELOPMENT_PROMPT.md`, ADRs, backlog, roadmap e documentação do módulo afetado.

## Função De Cada Documento

`AI_DEVELOPMENT_CHARTER.md` define o fluxo de trabalho, princípios de qualidade e regras permanentes de desenvolvimento com IA.

`ERP_DECISIONS.md` registra decisões de domínio e produto que não devem ser rediscutidas sem ADR ou task específica.

`ERP_GLOSSARY.md` mantém a linguagem oficial do ERP para reduzir ambiguidade entre documentação, código e conversas de planejamento.
