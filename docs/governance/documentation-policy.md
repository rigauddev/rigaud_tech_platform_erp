# Documentation Policy

Toda Task deve atualizar:

- documentação local do módulo;
- documentação central;
- mapa do produto quando status, modulo ou dependencia mudar;
- Help Center, tutorial ou FAQ quando houver superficie de uso;
- CHANGELOG;
- task registry;
- Academy;
- ADR quando houver decisão arquitetural.

Módulos devem manter:

- `README.md`
- `API.md`
- `DATABASE.md`
- `RULES.md`
- `TESTS.md`
- `ROADMAP.md`
