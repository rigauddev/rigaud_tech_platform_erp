# Products Overview

REST-001 inicia o cadastro de produtos da Rigaud Tech Platform ERP.

O módulo Products pertence ao Core compartilhado e será reutilizado pelo MVP Restaurante e por módulos futuros.

Escopo implementado:

- produto multi-tenant;
- criação;
- consulta por ID;
- listagem;
- filtros;
- paginação;
- atualização;
- ativação;
- desativação;
- disponibilidade para venda;
- exclusão lógica;
- preço de venda;
- custo;
- código interno;
- código de barras opcional;
- tipo de produto;
- unidade de medida;
- imagem principal por URL;
- auditoria;
- mensagens padronizadas da API;
- telas Flutter de lista, formulário e detalhe.

Fora do escopo:

- categorias;
- estoque;
- receitas;
- ingredientes;
- variações;
- adicionais;
- cardápio;
- pedidos;
- KDS;
- delivery;
- caixa;
- fiscal.
