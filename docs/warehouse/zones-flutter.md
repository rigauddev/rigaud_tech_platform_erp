# Warehouse Zones Flutter

REST-005 cria a feature:

```text
lib/features/warehouse_zones/
```

Estrutura:

```text
data/
domain/
presentation/
```

Telas:

- lista de zonas;
- cadastro de zona;
- edição de zona;
- detalhe da zona.

Fluxos preparados:

- ativar e inativar;
- alterar ordenação;
- associar zona a depósito ativo;
- navegar pelo menu principal.

A feature não adiciona dependências específicas de plataforma e permanece compatível com Web, Android, iOS, Windows, Linux e macOS.
