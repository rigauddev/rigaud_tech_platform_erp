# Warehouse Flutter

REST-004 cria a feature `warehouses`.

Estrutura:

```text
lib/features/warehouses/
  data/
  domain/
  presentation/
```

## Telas

- lista de depósitos;
- formulário de cadastro;
- formulário de edição;
- detalhe do depósito.

## Ações

- criar;
- editar;
- desativar;
- ativar;
- definir padrão;
- remover.

## Multiplataforma

A UI usa componentes Flutter compatíveis com Web, Android, iOS, Windows, Linux e macOS.

Nenhum plugin específico de plataforma foi adicionado.
