# Restaurant Operations Core

O Restaurant Operations Core e o domínio único para restaurante, bar, lanchonete, café, pizzaria, food truck e delivery. Cada segmento é configurado por filial e por recursos habilitados; não haverá um módulo isolado para cada formato de atendimento.

Esta documentação congela o contrato da DOC-011. Não implementa entidades, endpoints, telas, PDV, KDS, produção, fiscal ou financeiro.
