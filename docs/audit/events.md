# Audit Events

Eventos seguem padrão:

```text
<module>.<action>
```

Exemplos:

- `auth.login.success`
- `company.created`
- `user.password.reset`

## Products

- `product.created`
- `product.updated`
- `product.activated`
- `product.deactivated`
- `product.availability.changed`
- `product.deleted`
- `product.image.changed`
