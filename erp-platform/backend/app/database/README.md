# Database

Configuração base de banco de dados do backend.

Este pacote prepara:

- SQLAlchemy 2.x assíncrono.
- engine e sessão.
- `Base` declarativa.
- convenção de nomes.
- mixins técnicos.
- tipos compartilhados.
- contexto de tenant.
- health check de conexão.

Nenhuma entidade de negócio foi criada nesta etapa.
