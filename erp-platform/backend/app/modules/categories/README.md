# Categories

Módulo de Categorias de Produtos reutilizável por Restaurante, Loja de Roupas e futuros segmentos.

Responsabilidades desta task:

- CRUD de categorias multi-tenant.
- Hierarquia sem limite fixo de profundidade.
- Slug e código interno únicos por tenant.
- Soft delete.
- Ativação, desativação e ordenação manual.
- Auditoria dos eventos de categoria.
- Documentação do Form Blueprint inicial.

Fora do escopo:

- vínculo com estoque;
- vínculo com cardápio;
- presets automáticos por segmento;
- drag and drop funcional;
- bloqueios comerciais de SaaS.
