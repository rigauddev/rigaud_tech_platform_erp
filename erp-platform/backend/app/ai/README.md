# AI

Fundação reservada para recursos futuros de IA, agentes e integrações MCP.

Nenhuma funcionalidade de IA é implementada nesta etapa.

Diretriz:

- IA deve consumir eventos do ERP;
- agentes não devem acoplar regras de negócio;
- MCPs futuros devem atuar como camada de análise, recomendação e automação assistida;
- dados sensíveis devem seguir as regras de segurança, auditoria e tenant do ERP.
