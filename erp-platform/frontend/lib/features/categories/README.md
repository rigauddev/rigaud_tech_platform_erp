# Categories

Feature Flutter para Categorias de Produtos.

Esta feature cobre:

- lista hierárquica;
- cadastro;
- edição;
- ativar/desativar;
- remover categoria;
- preparação visual para árvore expansível.

Fora do escopo:

- drag and drop funcional;
- presets automáticos de Form Blueprint;
- integração com estoque, cardápio ou produtos.
