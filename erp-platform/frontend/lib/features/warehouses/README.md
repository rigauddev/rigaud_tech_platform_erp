# Warehouses

Feature Flutter para gestão de depósitos do Inventory Engine.

REST-004 adiciona:

- listagem de depósitos;
- cadastro;
- edição;
- detalhe;
- ativação/desativação;
- definição de depósito padrão.

A feature usa `data`, `domain` e `presentation`, com Riverpod, Repository Pattern e Dio.
