# Warehouse Locations

Feature Flutter para cadastro de localizações físicas do Warehouse Management.

Mantém MVVM, Riverpod, Repository Pattern e DataSource HTTP.

Escopo atual:

- listar localizações;
- cadastrar;
- editar;
- detalhar;
- ativar e inativar;
- reordenar;
- filtrar por depósito, zona e pesquisa textual.

Fora do escopo:

- leitura por câmera de QR Code ou código de barras;
- mapa visual do depósito;
- regras de picking, put away ou entrada de mercadoria.
