# ERP Blueprint

Projeto de documentação do blueprint do ERP, organizado com MkDocs.

Este espaço será usado para consolidar arquitetura, decisões técnicas, módulos, pesquisas, roadmap, backlog, prompts, templates e materiais de formação.

Nenhuma documentação funcional foi criada nesta etapa.

## Estrutura

- `mkdocs.yml`: configuração principal do MkDocs.
- `docs/`: conteúdo versionado da documentação.
