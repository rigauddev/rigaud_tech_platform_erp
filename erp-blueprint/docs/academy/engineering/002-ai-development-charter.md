# Academy — AI Development Charter

O `AI_DEVELOPMENT_CHARTER.md` é a constituição operacional do desenvolvimento com IA na Rigaud Tech Platform ERP.

Ele existe para manter ChatGPT, Codex e desenvolvedores humanos trabalhando com a mesma base de decisões.

## Por Que Existe

Projetos longos acumulam contexto.

Sem uma fonte permanente, decisões voltam a ser rediscutidas, módulos passam a usar nomes diferentes e pequenas divergências viram dívida técnica.

O charter evita isso ao tornar explícito:

- o fluxo obrigatório de task;
- as fontes que devem ser lidas;
- as regras permanentes de qualidade;
- o padrão Engine-first;
- a obrigação de documentação, testes, auditoria e demonstração.

## Base De Conhecimento

A partir da DOC-006, qualquer task deve considerar:

- `AGENTS.md`;
- `erp-blueprint/MASTER_DEVELOPMENT_PROMPT.md`;
- `AI_DEVELOPMENT_CHARTER.md`;
- `ERP_DECISIONS.md`;
- `ERP_GLOSSARY.md`;
- Task Registry;
- ADRs;
- documentação do módulo afetado.

## Resultado Esperado

Menos retrabalho, menos divergência e mais previsibilidade para cada nova entrega.
