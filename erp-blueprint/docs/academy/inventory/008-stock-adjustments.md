# Stock Adjustments

Um ajuste corrige um saldo por motivo operacional, como avaria, perda, validade expirada, devolução ou saldo inicial. Ele sempre cria um lançamento no livro razão de estoque.

Quando um ajuste foi lançado incorretamente, o sistema cria um ajuste compensatório. O registro original permanece íntegro para auditoria.
